# Notes: what came from where

Two reference sites were studied (see `../site-breakdown/BREAKDOWN.md`): a white corporate
investment-bank home page ("reference A", kaib-invest.com) and a dark trading-firm intro
("reference B", infinitefield.xyz). Only **ideas** were taken. Nothing was copied.

## Ideas borrowed from reference A (main page look)
- White page inside a thin vertical page frame; nav bar with a hairline underneath and pill buttons on the right.
- Near-black text, grey body copy, a single dark green accent.
- A large silver 3D infinity/Möbius loop as the hero, with part of its surface broken into small tiles,
  and a green glass cube as a secondary object.
- Label rows separated by hairlines (label on the left, grey text on the right), used here for
  Portfolio/Return/Tail, the Honesty list and the footer.
- Grey rounded cards with 3D renders and circular arrow buttons (inspiration links, chart cards).
- A plain accordion list (used here for the three VaR methods).
- Showing a risk warning in the footer.

## Ideas borrowed from reference B (opening sequence)
- Dark charcoal opening screen with a glowing orange/yellow wave ribbon.
- Labels pinned to the four corners, "Scroll To Start" top right.
- Scroll as narrator: wave -> blurred field -> black/white blocks -> finer checkerboard -> diagonal wipe.
- Text that lights up word by word, and a symbol "decode" effect.

## How they are intertwined (not pasted)
- The intro's checkerboard wipe ends on pure white, which *is* the main page background, so the dark
  sequence hands over to the bright page without a cut.
- The intro's orange is reused only for danger: tail bars in the histogram, the worst 5% of price
  paths, model breaks in the backtest, crisis bars, orange dice in the Monte Carlo render, the worst
  stress bar in the 3D chart. Green marks the safe side (days inside the VaR line, expected
  breaks, the Basel green zone, positive shocks).
- The hero's tile region echoes the intro's blocks; the wave comes back, calm, in the footer.

## Originality check
- **Code**: all written for this project. (v2: the page no longer loads three.js; the hero is a pre-rendered video.) The intro wave is an original fragment shader (summed
  sine strands + fbm noise + block/checker/wipe stages), not the reference's code. No GSAP, Lenis or
  SplitText; scroll effects are a small requestAnimationFrame loop. Third-party code is limited to
  three.js (MIT) and the Inter font (SIL OFL), both installed from npm and vendored.
- **3D (v2)**: every model, texture and light is generated by the scripts in `blender/` from maths
  (bmesh/numpy); no downloaded models, textures or HDRIs, and no paid AI generation. The studio lighting is
  a hand-built rig of emissive cards and a gradient world. The detail maps (panel lines, circuit traces,
  brushed streaks) are drawn procedurally in `blender/v2_textures.py`.
- **Text**: all copy comes from `risk-engine/site/index.html`, plus a few new connective lines
  (eyebrow captions, risk warning wording, image alt text). None of the references' text is used.
- **Brand**: reference A's name and logo do not appear anywhere on the site (checked with a search of
  `index.html`, `css/`, `js/`, `assets/`). Reference B is named only where the original explainer
  already listed it as an Awwwards inspiration (section 08), linking to its Awwwards page.
- **Assets**: no images, video, fonts or icons were downloaded from either reference.

## Number check (ported charts vs original)
Both sites were served locally and driven with the same inputs in a real browser. All 12 compared
readouts were identical, text included:
- Confidence 90 / 95 / 97.5 / 99 / 99.5 / 99.9%: VaR, ES, bell-curve VaR and the sentence
  (e.g. 99%: VaR 2.30%, ES 2.84%, bell-curve 1.98%, "...under $22,972 ... averages $28,378.").
- Shock presets: 2008-style -15.0% / −$150,000; Stocks + bonds fall and Flight to safety also match.
- Backtest tabs: Historical 73 / 0.001, Normal 94 / 0.000, Expected 47 / —, with the same text.
The method cards still show 2.12/3.15, 1.81/2.08, 2.03/2.73 (VaR/ES %) and the stress bars
−12.1/−4.6/−14.2/−22.9%.

## Changes from the original on purpose
- The old hero animation (140 simulated price paths) now lives in section 01 as a chart card.
- Dropped: the cursor glow and card tilt (they don't fit a calm white page).
- Each method's accordion panel has a Blender render that illustrates it.

## v2 changes (premium models, calmer hero)
- Models rebuilt for product-render quality (see README "What the models are"); renders in Cycles at 2400 px.
- Mid-way the user asked that the infinity loop must not move. The hero is therefore fixed like reference A's,
  and its motion is a calm, seamless 6-second Blender loop (shimmering tiles, a light sweep, a few cubes lifting
  and settling) instead of a live, rotating WebGL model. A scroll-driven camera flight and tile-dissolve shader
  were built first and then removed for this reason. Section props are Cycles renders with a slow light sheen
  (the live WebGL versions looked flatter than the renders).
- Fixed: the intro corner labels get a chip (dark over the blocks, white with a hairline once the page turns
  white), so the bottom-right label stays readable over the checker; "Scroll To Start NN" fades out as the page
  turns white and a section indicator (left margin) takes over on the main page; the empty band under the hero
  buttons is now a row of counters.
- Number check repeated for v2: 13 readouts (6 confidence levels with sentence, 4 presets, 3 backtest tabs)
  identical to the original.
