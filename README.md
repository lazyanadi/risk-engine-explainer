# KAIB-style site

A new site in the style of kaib-invest.com: bright corporate layout, silver 3D visuals,
one green accent, hairline borders, pill buttons. 3D assets are made in Blender and
exported as video or glTF.

Reference breakdown: ../site-breakdown/BREAKDOWN.md

## Layout
- index.html  page
- css/        styles
- js/         scripts
- assets/     images, video, glTF
- blender/    .blend source files
- docs/       notes
